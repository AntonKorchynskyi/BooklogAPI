# WebAPI_Assignment2_PartC
 
## Project Description
This project is my Assignment 2 for the Web Frameworks and APIs course, which is called BookLog API. The API enables users to view, add, update, and delete book records, with the additional options to filter results in GET requests and get recommendations based on their current book list. 

## Tools used
 - Node.js
 - Express.js
 - MongoDB
